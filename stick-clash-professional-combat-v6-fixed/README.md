# Stick Clash — Shadow Sword V5

Professional stickman 1v1 fighter with:
- Play With Bot solo mode
- mobile virtual joystick and touch combat controls
- punch, kick, heavy punch, dash, block, jump
- sword equipped on both fighters
- dedicated Sword Slash combat action (U on keyboard / ⚔ mobile button)
- sword damage, range, knockback and active frames
- procedural sword draw/hold/slash animation with blade trail
- continuous ground with no holes or ring-outs
- 120-second rounds, best of 3

## Run
1. Install Node.js 18+
2. Open this folder in a terminal
3. `npm install`
4. `npm start`
5. Open `http://localhost:3000`
